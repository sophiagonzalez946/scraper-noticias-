# scraper de libros

Proyecto de web scraping desarrollado en Python utilizando BeautifulSoup

## Lo que hace 
 Extrae los titulos, precios, enlaces y puntuaciones de cada libro y lo guarda en un archivo CSV.

## Herramientas
 -Python
 -Requests
 -BeautifulSoup
 -CSV

## Instalacion
 ```bash
pip install -r requirements.txt
```

## Ejecución

```bash
python main.py
```
